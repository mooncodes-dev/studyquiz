운영체제는 컴퓨터 하드웨어와 사용자 사이에서 자원을 관리하는 시스템 소프트웨어이다.
운영체제는 프로세스 관리, 메모리 관리, 파일 시스템 관리, 장치 관리라는 네 가지 핵심 기능을 수행한다.
커널은 운영체제에서 가장 핵심적인 부분으로, 메모리에 상주하며 하드웨어를 직접 제어한다.
사용자 프로그램은 시스템 콜을 통해 커널에 서비스를 요청한다.
시스템 콜은 사용자 모드에서 커널 모드로 전환되는 통로 역할을 한다.
인터럽트는 하드웨어나 소프트웨어가 CPU에 보내는 신호로, 현재 작업을 잠시 멈추고 정해진 처리를 수행하게 한다.
인터럽트가 발생하면 CPU는 인터럽트 핸들러를 실행한 뒤 원래 작업으로 복귀한다.
프로세스는 실행 중인 프로그램을 뜻하며, 코드와 데이터와 힙과 스택으로 이루어진 메모리 공간을 가진다.
운영체제는 각 프로세스를 관리하기 위해 프로세스 제어 블록, 즉 PCB에 프로세스의 상태와 정보를 저장한다.
프로세스는 생성, 준비, 실행, 대기, 종료의 다섯 가지 상태를 오가며 동작한다.
스레드는 프로세스 안에서 실행되는 흐름의 단위로, 프로세스의 메모리를 다른 스레드와 공유한다.
하나의 프로세스는 여러 개의 스레드를 가질 수 있고, 스레드들은 서로 독립적으로 스케줄링된다.
스레드는 스택과 레지스터를 각자 가지지만 코드와 힙 영역은 프로세스 안에서 공유한다.
다중 스레드를 사용하면 하나의 프로세스 안에서 여러 작업을 동시에 진행할 수 있다.
스케줄링은 어떤 프로세스에게 CPU를 할당할지 결정하는 운영체제의 정책이다.
선입선출 스케줄링은 준비 큐에 먼저 도착한 프로세스를 먼저 실행하는 가장 단순한 방식이다.
최단 작업 우선 스케줄링은 실행 시간이 짧은 프로세스를 먼저 실행해 평균 대기 시간을 줄인다.
라운드 로빈 스케줄링은 각 프로세스에게 일정한 시간 할당량을 번갈아 부여하는 방식이다.
시간 할당량이 너무 크면 라운드 로빈은 선입선출과 비슷해지고, 너무 작으면 문맥 교환이 자주 일어난다.
문맥 교환은 실행 중인 프로세스의 상태를 저장하고 다른 프로세스의 상태를 복원하는 과정이다.
문맥 교환이 일어나는 동안 CPU는 실제 작업을 하지 못하므로 문맥 교환은 오버헤드에 해당한다.
메모리 관리는 여러 프로세스가 한정된 메모리를 안전하게 나누어 쓰도록 조정하는 일이다.
가상 메모리는 실제 메모리보다 큰 주소 공간을 프로세스에게 제공하는 기술이다.
페이징은 가상 메모리를 고정된 크기의 페이지로 나누고, 물리 메모리를 같은 크기의 프레임으로 나누어 관리하는 방식이다.
페이지 테이블은 가상 페이지가 어느 물리 프레임에 있는지를 기록하는 자료구조이다.
프로세스가 접근한 페이지가 메모리에 없으면 페이지 폴트가 발생하고, 운영체제는 디스크에서 페이지를 가져온다.
페이지 교체는 메모리가 가득 찼을 때 어떤 페이지를 내보낼지 결정하는 과정이다.
선입선출 페이지 교체와 최소 최근 사용 페이지 교체는 대표적인 페이지 교체 알고리즘이다.
파일 시스템은 데이터를 파일 단위로 저장하고 이름으로 찾아 쓸 수 있게 해 주는 체계이다.
디렉터리는 파일들을 묶어 계층 구조로 조직하는 역할을 하며, 파일의 위치를 찾는 출발점이 된다.
파일 시스템은 파일의 메타데이터를 함께 저장해 파일의 크기와 소유자와 접근 권한을 관리한다.
교착 상태는 두 개 이상의 프로세스가 서로 상대가 가진 자원을 기다리며 영원히 멈추는 현상이다.
교착 상태가 발생하려면 상호 배제, 점유와 대기, 비선점, 순환 대기라는 네 가지 조건이 동시에 성립해야 한다.
세마포어는 공유 자원에 대한 접근을 조절하는 정수 변수와 대기 큐로 이루어진 동기화 도구이다.
뮤텍스는 한 번에 하나의 스레드만 임계 구역에 들어가도록 보장하는 잠금 장치이다.
임계 구역은 공유 자원을 사용하는 코드 구간으로, 동시에 두 스레드가 실행하면 문제가 생길 수 있다.
캐시는 자주 쓰는 데이터를 빠른 저장 장치에 복사해 두어 전체 접근 속도를 높이는 장치이다.
CPU 캐시는 메인 메모리보다 훨씬 빠르지만 용량이 작아 적중률이 성능을 좌우한다.
다중 프로그래밍은 여러 프로세스를 메모리에 올려 두어 CPU가 쉬는 시간을 줄이는 기법이다.
시분할 시스템은 여러 사용자가 동시에 컴퓨터를 쓰는 것처럼 느끼게 하는 운영 방식이다.
가상화는 하나의 물리 컴퓨터 위에서 여러 개의 가상 컴퓨터를 실행하는 기술이다.
하이퍼바이저는 가상 머신을 만들고 관리하는 소프트웨어로, 가상화의 기반이 된다.
장치 드라이버는 운영체제와 하드웨어 장치 사이에서 통신을 담당하는 프로그램이다.
버퍼링은 속도가 다른 장치 사이에서 데이터를 임시로 저장해 흐름을 맞추는 기법이다.
스풀링은 프린터처럼 느린 장치의 작업을 디스크에 쌓아 두고 순서대로 처리하는 방식이다.
보안은 운영체제가 사용자를 인증하고 파일마다 접근 권한을 검사함으로써 유지된다.
운영체제의 성능은 응답 시간, 처리량, 자원 활용률을 기준으로 평가할 수 있다.
현대의 운영체제는 이 모든 기능을 조합해 안정적이고 효율적인 실행 환경을 제공한다.
